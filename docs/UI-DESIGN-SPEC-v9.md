# WorkOn 界面设计规格 v9 —— 对话即界面

> 原型：`workon-ainative-prototype.html`（双击打开，可直接说话试）
> 适用代码：`src/renderer/` · 令牌 `index.css` · 壳层 `App.tsx` · 首页 `HomeView.tsx` · 悬浮件 `SuggestionWidget.tsx`
> **v8（看板 + AI 编排版面）已被 v9 取代**，保留在 `UI-DESIGN-SPEC-v8.md` 供对照。

---

## 0. 为什么从 v8 改到 v9

v8 做的是「把 SaaS 看板换成 AI 编排的看板」。评审后暴露出四个问题：

| 问题 | v8 的做法 | v9 的做法 |
|---|---|---|
| 首次上手还是难 | 空状态只是"没有推荐"，用户不知道能问什么 | 面板**真的是空的**，姵儿先开口问一句话 |
| 千人千态靠算法猜 | 编排引擎按评分排序模块 | **你说什么，它就长什么** —— 内容由对话决定 |
| 链路/进度太复杂 | 泳道、进度链、分层卡片 | 链路一条线，进度一张平铺表 |
| 建议需要主动找 | 建议在页面里 | **主动弹窗送到你面前**，5 秒后收成胶囊 |

**核心转变：从「AI 编排一个界面」变成「界面是对话的产物」。**

后者才是真正的 AI-native —— 千人千态不再需要算法去猜，而是自然发生：
聊工作就长链路和项目，聊习惯就长留痕和方法，聊生活就长生活类卡片。

┌──────────────────────────────────────────────────────────┐
│ 姵儿 WorkOn      9月29日 周二 15:34    搜索  设置  ✕    │  46px，无导航
├────────────────────────┬─────────────────────────────────┤
│                        │  今天 4 │ 任务 2 │ 记忆 2      │
│   对话                  │  [全部][工作][生活][留痕][方法]   │
│   （姵儿说话）          │                                 │
│   右下角标「长出了什么」  │   卡片（对话聊出来的）             │
│                        │                                 │
│  ┌──────────────────┐  │                                 │
│  │ 说点什么…      ↑  │  │                                 │
│  └──────────────────┘  │        ┌──────────────┐        │
│  [快捷短语 ×6]         │        │ 工作建议弹窗   │        │

**没有侧栏。** 12 个导航项全部消失：

| 原来 | 现在 |

| 报表 / 热度图 / 画像 / 问答 | 「记忆」tab + 直接问 |
| 知识库 | 留痕卡里的「写在哪 → 知识库 3 篇」直达 |
| 桌搭 | 3D 姵儿常驻桌面 + 「陪伴」用对话进入 |
| 隐私 | 留痕/方法卡里直接可删可关 |
| 设置 | 顶栏齿轮 |

## 2. 首次进入：零卡片

这是 v9 最重要的一个决定。

**第一次打开，面板是空的。一张卡都没有。**

姵儿只说两句话：
1. 「我是姵儿。就住在你桌面上……是为了你卡住的时候递一把。」
2. 「先不给你任何看板。**说说你今天要做什么**，剩下的我来摆。」

面板显示：

```
        ( ◌ )
   这里还什么都没有
跟姵儿说一句话，需要什么它就摆什么。
不会一次给你 12 个板块。

[我的项目进度]  [今天有哪些待办]
[我现在在哪个链路] [我今天专注怎么样]
```

那 4 个虚线按钮是**种子问题**，点了等价于你说了这句话 —— 它演示了「主动增加想要展现的模块」。

**规则：新用户前 3 天，面板卡数不超过 3 张，且必须由对话触发。**

## 3. 对话生卡片（核心机制）

### 3.1 六个卡片类型

| 类型 | 触发时机 | 形态 | 归属 tab |
|---|---|---|---|
| `项目` | 问进度/某项目 | 平铺表 | 任务 |
| `待办` | 问今天做什么 | 勾选列表 + 时间 | 任务 |
| `链路` | 问卡在哪/下一步 | 一条线 + 断点 | 今天 |
| `建议` | 没匹配到 → 兜底 | 一句话 + `+` 按钮 | 今天 |
| `留痕` | 说了偏好/规矩 | 标题 + 标签 + 双数据格 | 记忆 |
| `方法` | 问怎么做好 | 标题 + 左右对比 + 打包条 | 记忆 |
| `专注` | 问摸鱼/分心 | 结论 + 分段时长 | 今天 |

### 3.2 聊天里的「出生标记」

姵儿每给一次结构化产出，气泡下方挂一个标记：

> 右边长出了 **2 个模块**：`项目` `留痕`

用户永远知道**它为什么现在变多了**。这是 v8「为什么今天是这 5 块」的可解释性，但轻得多 —— 不需要用户主动去查。

### 3.3 同类不堆叠

同类型卡片刷新而非追加，面板里同一种永远只有一张。
（否则多聊几轮就会出现 5 张项目表。）

### 3.4 数据模型

```ts
type CardType = 'project'|'todo'|'chain'|'suggest'|'trace'|'method'|'focus'

interface BoardCard {
  id: string
  type: CardType
  title: string          // 留痕/方法的一句话判断
  body: ReactNode        // 结构化内容
  cat: '工作'|'生活'|'留痕'|'方法'
  bornFrom: string       // 触发它的那句话，用于溯源
}
```

## 4. 链路：一条线，不是一张图

v8 的泳道和分层进度全部砍掉。

```
  ●━━━━◉━━━◉━━━○━━━━○
读需求  写接口  自测   联调
              ↑红点=断点
```

- 横向一行，节点 11px，当前节点脉冲
- **断点标一个红点**，不标文字
- 下方一句话说明原因，不展开

> 你 14 天里 **9 次断在「自测」**。不是懒 —— 你的自测环境冷启动要 6 分钟，这 6 分钟里你切走了。
> `[每天 09:15 预热]` `[不对，是别的原因]`

**规则：一行 + 一句原因 + 两个动作。多一个字都不要。**

## 5. 待办与项目：平铺

```
项目            今日     进度                状态
DWS 接口开发     0/4     ▬▬░░░░░░░  10%    ● 逾期 2 天
WorkOn          1/7     ▬▬▬▬▬░░░░  43%    ● 进行中
Oner            0/6     ▬▬▬▬░░░░░  32%    ● 需求变了
OnDesign         —      ░░░░░░░░░   —     ● 未拆任务
OnKnow           —      ▬░░░░░░░░   6%    ● 3 天没动
```

硬性规则：

1. **行高 34px**，一屏 10 行，不折叠
2. **状态用 7px 色点 + 文字**，**不用彩色标签块**（标签块是噪音，v8 满屏都是）
3. **不用泳道、不用分组、不用卡片套卡片**
4. 逾期排最前，排序即优先级 —— 不用额外的排序控件
5. 进度条 64px 定宽 + 百分比等宽数字，不让列跳动

待办用 17px 圆角勾选框 + 行内时间，不做卡片。

## 6. 工作建议弹窗（重点）

这是用户明确点名要的东西，也是 AI-native 相对 SaaS 最实在的差别：**它会来找你**。

### 6.1 形态

```
┌──────────────────────────────────┐
│ (姵) 姵儿 · 工作建议      刚刚  ✕ │
│ DWS 接口逾期 2 天，今天只推进 10% │
│ 依据  · 逾期 2 天 · 今日 10% · 联调卡住 │
│ [排到明早 09:30] [先不管]  别再提醒 │
└──────────────────────────────────┘
        ↓ 5 秒后自动收成
┌────────────────────────────────────┐
│ (姵) 姵儿 · 刚刚         →   ✕     │
│     要排到明早 09:30 吗              │
└────────────────────────────────────┘
```

### 6.2 三条硬规则

| 规则 | 说明 |
|---|---|
| **不叠加** | 同一时刻最多 1 张。新的来了先等旧的被处理 |
| **5 秒自动收胶囊** | 不读就收成一个小胶囊（44px 高），点一下再展开。胶囊上直接能给答案 |
| **关掉有代价** | 点「别再提醒」→ 这类提醒 45 分钟内不再出现；点 ✕ → 45 分钟内不再主动 |

### 6.3 什么时候才主动开口

三个条件**同时**满足，缺一不弹：

```
① 你停手 > 25 分钟（不是切窗口，是真停）
② 有明确后果（逾期 / 联调卡住 / 会议要来不及）
③ 你历史上接受过同类提醒（点过「好」而不是「别再提醒」）
```

外加**每日预算 4 次**。用完就闭嘴。

> v8 的「主动预算」只是写在文档里的原则，v9 把它变成了弹窗的实际行为。

### 6.4 跟 3D 姵儿的关系

桌面的 3D 角色在这条建议弹出时**抬头 + 说话**，弹窗的文案就是气泡文案。
主窗口里只有卡片，桌面上才是"它在跟你说话"。两条通道，同一份内容。

## 7. 卡片模板规范

以 `留痕` / `方法` 为例（其余同构）：

```
┌──────────────────────────────────────────┐
│ [icon] 留痕 · 我看懂的那条规矩              │  ← 类型标签，22px 图标底
│ 你不是在攒文件，你是在给未来的自己留证据     │  ← 15px/23 600，一句判断
│ 你在做 DWS 联调时，会刻意把「怎么绕过去」…  │  ← 13px/20 tx2
│ 你留下的痕迹                               │
│ [踩坑][踩坑][决定][已归档]                 │  ← 标签，主态用 accent 实心
│ ┌────────────┐ ┌────────────┐             │
│ │ 写在哪      │ │ 最近一次    │             │  ← 双数据格
│ │ 知识库·3 篇 │ │ 9 月 21 日  │             │
│ └────────────┘ └────────────┘             │
│ 以后我看到你反复踩同一个坑，会直接递给你 →已自动开启 │  ← 打包条
└──────────────────────────────────────────┘
```

**统一结构：类型标签 → 一句判断 → 解释 → 结构化字段 → 行动。**

这条结构让 AI 的产出有稳定的视觉形状，而不是每次长一个样。

## 8. 设计令牌（沿用 v8，已修掉冷暖撞车）

### 表面：单一色相族

```css
[data-mode="light"]{
  --canvas:#F3F1ED;   /* 暖纸画布 */
  --s1-bg:#FFFFFF;    /* 卡片：中性白，不带色相 */
  --s2-bg:#FAF9F7; --s3-bg:#F1EFEB; --inset:#F5F4F1; --chrome:#EFEDE8;
  --line:#E6E2DA; --line-2:#D7D2C8; --line-3:#C4BEB2;
  --tx1:#17161A; --tx2:#54514A; --tx3:#8A867C; --tx4:#ADA79A;
}
[data-mode="dark"]{
  --canvas:#0D0E11; --s1-bg:#15171B; --s2-bg:#1B1E23; --s3-bg:#23262C;
  --inset:#101216; --chrome:#111318;
  --line:rgba(255,255,255,.075); --line-2:rgba(255,255,255,.13);
  --tx1:#ECEDEF; --tx2:#A3A7AF; --tx3:#70747E; --tx4:#4B4F58;
}
```

> 修掉的是现有 `ink` 浅色主题「暖米画布 `#F7F4EE` + 青瓷绿卡片 `#E9F1EC`」的冷暖打架。

### 语义色：一个颜色只做一件事

| 令牌 | 浅色 | 唯一职责 |
|---|---|---|
| `--accent` | `#0E8C7F` | 选中态 / 主按钮 / 进度 / 焦点 |
| `--ok` | `#15803D` | 已完成 |
| `--warn` | `#B45309` | 逾期 / 临期 / 风险 |
| `--danger` | `#DC2626` | 破坏性操作 / 错误 / 断点 |
| `--slack` | `#C2703C` | 摸鱼（**不用红色**） |
| `--focus` | `#2F7DD1` | 工作时长 |
| `--aura` | 紫→青 | **仅 AI 语义面** |

> 浅色强调色必须压深到 `#0E8C7F`。现在的 `#0FB5A4` 在白底上做 12px 小字只有约 2.3:1，这是浅色模式"发飘看不清"的根因。

### 圆角 / 阴影 / 动效

```css
--r-xs:6px; --r-sm:8px; --r-md:12px; --r-lg:16px; --r-xl:20px; --r-full:999px;
/* 替换现有的 10/14/18/22 —— 4 个非标值只会导致随手乱用 */

--e1:0 1px 2px rgba(28,24,18,.05);
--e2:0 1px 2px rgba(28,24,18,.05),0 4px 12px -3px rgba(28,24,18,.07);
--e3:0 2px 4px rgba(28,24,18,.05),0 12px 28px -8px rgba(28,24,18,.12);
--e4:0 8px 20px rgba(28,24,18,.10),0 28px 64px -14px rgba(28,24,18,.20);

--e-out:cubic-bezier(.22,1,.36,1); --e-sp:cubic-bezier(.34,1.32,.64,1);
--t-mi:120ms; --t-hv:160ms; --t-pn:240ms; --t-pg:320ms;
```

字体栈：**CJK 优先**（桌面 CJK 应用，不能用纯拉丁字体）
`Outfit, MiSans, HarmonyOS Sans SC, PingFang SC, Noto Sans SC`
拉丁与数字用 Outfit / JetBrains Mono，中文回落系统栈。
Electron 打包时 Outfit / JetBrains Mono 需**本地内置**，不要走 CDN。

### 图标

全部内联 SVG：24 网格 / 1.8 描边 / 圆头圆角。
**替换 `App.tsx` 里的 emoji（🏠📅🎯）和字符按钮（`– ▢ ✕`）。**

## 10. 怎么验这个方案成立

打开原型，做三件事：

1. **什么都不点**，看 30 秒 —— 首次上手的成本是不是真的降下来了
2. 点底部 6 个快捷短语里挑 2–3 个 —— 面板的卡片是不是**跟着你的话长出来**
3. 看右下角那个胶囊 —— 它是不是"不打扰但一直在"

第 2 条是唯一的关键：**卡片由对话决定，而不是由算法排序决定。**
这就是 AI-native 和"带 AI 功能的看板"的分界线。
