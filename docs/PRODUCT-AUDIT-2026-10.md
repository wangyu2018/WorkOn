## 1. 五价值观审判（人性化主轴）

### 1.1 注意力预算 —— 「名存实亡 ⚠️ 最大违规区」
设计承诺：打扰要配得上、问卡日限 2。实际五路绕闸：
1. **轻问诊完全绕过日限**：index.ts:104-117 每 30 分钟直弹，不进 confirmQueue、不耗配额，低专注的下午可连环中弹
2. **浏览器-计划确认卡直发** widget，不走队列不查 canInterrupt（monitor.ts:292-310），一天多计划可连弹
3. **pushNotify 全链路无预算门**（notify.ts:45-46）：里程碑庆祝高专注时照弹（care.ts:71-88）
4. **配额入队即烧**（attributions.ts:161）+ 队列 TTL 仅 5min：专注 5 分钟回来，问题死了但今日额度没了
5. **"日限 2"本身是虚的**：三套计数器互不相通、deliveredCount 重启清零（confirmQueue.ts:23-24）、日界 UTC/本地三处不一致（东八区跨午夜错乱）

另：**care.ts 并未封存**——`petCareEnabled: true` 是默认值（types.ts:1099），整点轻问候 7 条/天 + 2h 休息提醒，最坏 8-12 次/天软打扰。交接文档说"封存"与代码不符。

### 1.2 诚实的不确定性 —— 「有暗洞」
- 好的一面：AI conf≥0.8 不覆盖规则字段真实现（aiEnhancement.ts:134-141）
- 暗洞①：`entry.confidence = Math.max(confidence, aiConf)`（:148）——**AI 自报置信度无条件抬高条目置信度**，0.8 锁定可被吹到 0.95，置信度语言被 AI 自我加冕污染
- 暗洞②：规则路径恒返回 `confidence = 1`（decision.ts:89）——规则的"确定性"是虚标

### 1.3 零认知成本 —— 「当前最大失败项」
首启即流失链（详见 §4 首启）：无引导 + 桌宠 20s 迟到 + AI 默认死 + mac 静默空转 + 首页 19 块 60+ 控件。日常使用里的死物：托盘"悬浮窗"勾选无效（tray.ts:81-85 只写设置不动窗）、桌宠控制栏六按钮永不显示（showCtlBar 无调用点，pet/main.ts:579-609）、compact 态是幽灵（全部入口强转 full，windows.ts:422-423）、对话窗关不掉挪不动（无关闭钮无 Esc 无拖拽区）。

### 1.4 先猜后问 —— 「做得最好的一条 ⭐」
- 归属纠错 **2-3 次点击 0 个字**（问卡内嵌纠正卡，SuggestionWidget.tsx:1436-1448）
- 存疑降级为琥珀芯片而非提问（attributions.ts:618-633）——教科书级实现
- 反例 3 个：空泛问诊问系统自己能答的问题（questionGenerator.ts:13-24）、persona_gap 三连问已有数据可推导（:27-31）、浏览器→计划匹配要人确认而归属引擎自己就是"低置信挂上标存疑"做对了没推广（monitor.ts:296-308 vs attributions.ts:425-433）

### 1.5 本地优先 —— 「原则守住，边界破了两条」
- 五步脱敏网关在（desensitize），原始数据不出网 ✅
- **破口①**：作者私人和风天气 API Key 打包进客户端默认值（types.ts:1137-1138）——密钥泄漏 + 用户流量走作者账号
- **破口②**：默认 `wsEnabled:true` 开 18765 本地 WS 端口，新用户不知情

## 3. 模块关联断点（该联动而断开的）

1. **问卡生态三头蛇**：confirmQueue（队列+TTL）/ attributions（持久化配额）/ index.ts 轻问诊（裸发）——三套互不知道彼此存在 → v10 消息总线正是解药
2. **设置五处分叉**：同一批桌面组件开关在 SettingsView 和 BuddyStage 双头维护，todoWidget:display 通道断线
3. **纠正好路径没推广**：归属引擎的「低置信挂上+标存疑+琥珀芯片」是全产品最好的人性化实现，但计划匹配/浏览器确认没有复用它
4. **care 与注意力预算从未握手**：care 是消息源但没有 canInterrupt 门；notify 是出口但无优先级字段
5. **识别模式与用户永远隔离**：shadow/model_first 的价值（jev 接入的前提）埋在开发者选项后面

## 6. 用户试用脚本（mac 实测 12 条，每条 1-3 分钟）

> 用法：逐条走，对照「预期 vs 实际」，标出你不爽的点。mac 上 L1 采集不工作属已知降级（F3），重点测交互与信息架构。

1. **冷启动第一眼**：关掉应用重新 `npm run dev`。盯前 25 秒——预期产品有脸有人格；实际：splash 闪 1.5s → 深色仪表盘 19 块 → 20s 后桌宠才出现（F4/A1）
2. **找桌宠的控制栏**：桌宠出现后悬停/右键找操作按钮。预期有聊天/收纳等入口；实际：控制栏六按钮永不显示，右键无反应（D2，chat:false）
3. **完成一个待办**：不看不查直接操作。这条是全应用最好的路径（首页勾选 1 击）——感受一下"好"长什么样，再对比下一条
4. **问 AI 一个问题**：问答页或桌宠聊天。预期引导配置；实际：本地模式横幅/「还没配置 AI 模型哦~」，但没有任何"去配置"的一键入口（F5/F6 相关）
5. **关掉主窗口**：点红叉，看进程/托盘。预期退出；实际假退出且零提示（F10）
6. **托盘菜单逐项点**：重点点「悬浮窗」勾选和看「暂停记录」标签。实际：勾选无效（D1），Ctrl+Alt+P 标签与实际功能矛盾（D5）
7. **Alt+Space 呼出对话窗，然后试着关掉它**：找关闭钮/Esc/拖动。实际：都没有，只能再按一次 Alt+Space（D8）；mac 上这个键还可能撞输入法
8. **悬浮窗展开**：设置里打开悬浮窗，单击胶囊。实际：无反应，要双击，提示藏在悬停 title（D4）
9. **数设置**：打开设置页+隐私页+搭子页，感受控件总量（90+）；试着找「识别引擎模式」——藏在 系统→开发者选项 里（A3/C6）
10. **切换视角**：侧栏顶部切三个视角，看「报表/隐私」入口是不是时而出现时而藏进「更多」（A4）
11. **隐私自查**：隐私页找「它现在正在记录我什么」。预期有总开关/当前采集状态；实际只有排除名单和清理——且默认已在记录而你从没同意过（F1）
12. **概念测试**：自问五个词的区别——主线/项目/计划/安排/待办；以及 姵儿/搭子/虚拟角色/桌宠 是不是一个东西（A2）。如果你自己都要想一下，用户必挂
