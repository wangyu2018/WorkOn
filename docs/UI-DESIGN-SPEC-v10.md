# WorkOn 设计规格 v10 ·「一面一角色」

> 2026-10-09 · **本文取代 v7/v8/v9 三套分立表述，是唯一实现依据。**
> 血统：v7「左问右表」（版面与拆机制）× v9「对话即界面」（首启与壳层）× v8/9.1「模块注册表」（底座）× SIGNALS（信号层）+ 本周拍板的七项决策（指引式首启 / 提醒中心 / 第六去向 / 桌面层简化 / 主动消息总线 / 交互自进化 / jev 三层分工）。
> 竞对标尺：Today.ai（todayai.cn）=「云上秘书」；WorkOn =「桌边同事」。它靠连接器知道你*计划*什么，我们靠本地采集知道你*实际*在干什么。

---

## 0. 不变的根（五价值观 + 竞争定位）

1. **本地优先**：原始数据（窗口/文件/OCR）止步本地；云端 LLM 只见脱敏决策流
2. **注意力预算**：打扰要配得上；置信度是界面语言
3. **诚实的不确定性**：存疑标存疑；显示的概率必须真校准（jev 温度表）
4. **零认知成本**：打开即有脸；三键人生（看/答/拖）；碰过续命；消除不丢
5. **先猜后问**：按最佳猜测行动，纠正要容易

差异化护城河（竞品结构上做不了的）：**行为层感知**（窗口/UIA/键鼠/AI 工具监控）× 本地小模型决策（jev，免费离线高频）× 桌面陪伴层（桌宠）。

## 1. 总形态：一面一角色

```
┌─ 主窗（唯一的"面"）──────────────────────────────┐
│ 左问（360px 对话流）      │ 右表（活页）           │
│ · 你的话=墨竖线引文       │ · 报头 sticky          │
│ · AI 答=◇Aura kick+可拆件 │ · 折上（你的版面）      │
│ · AI 主动发起（同为 ◇ 标） │ · 折线                │
│ · 待处理行（未读主动消息）  │ · 折下（TTL 推送区）    │
│ · 输入场+建议 chip        │                       │
└──────────────────────────┴───────────────────────┘
桌宠（唯一的桌面常驻）+ 可选待办树    镜（后台：设置/记忆/隐私/习惯/例程）
```

**退役清单**：悬浮窗 SuggestionWidget（三态/吸附/呼吸圈/dock）整体退役；右键聊天面板并入主窗对话流；perspective.ts 晨昼晚视角删除路由层（时段逻辑降级为后台编排权重因子）；16 视图全部坍缩（归宿见 v7 §2.8，新增：监控数值→报头+桌宠状态）。

## 2. 首启：指引三步 + 协议启蒙（一次，两分钟）

**不是零卡片，是带着地图进门。**

1. **报头生成**：一行「你主要做什么工作？」；若已检测到工作痕迹（装过的 IDE/常开应用），先猜好让你确认——先猜后问
2. **模块选择**：按画像给种子包（开发者包=待办+专注时间线+AI 助手状态+代码产出；创作者包=待办+素材库+截屏时间线……）+ 23 模块抽屉全量自由勾选。选中的进折上，没选的留抽屉
3. **提醒意愿 + 协议启蒙**：桌宠现场演示一条气泡——「这是以后我找你的样子：① 好，知道了 ② 别这样问」——回 1（或点①），快捷回复协议即建立，顺带测通通道；问一句「要每晚 X 点看今日章吗？」种下第一条例程

**对话式引导并行**：首启后左栏 AI 一句欢迎 + 三个建议 chip（看看你今天的时间线 / 加一条待办 / 设个晚上提醒）。勾选和对话两条路到达同一个结果。

## 3. 主窗右栏：活页（继承 v7，不改动）

报头 sticky（唯一永久物，双态，存疑→琥珀脊）；折上=你的版面（垂直重排+半栏双拼）；折线（虚线分界，空时隐藏）；折下=新落推送区（TTL 衰减→褪色→坍缩；碰过续命；消除摘要入账可召回）。栏目=三段式（◇来源行→主角→meta），无框无底色，发丝线分隔。钉住=青瓷+实脊；AI 新生=裸落纸面+aura 脊。

**一人一面 = 版面是长出来的**：首启种子 → 来件/问答/观察不断落折下 → 留住进折上 → 每个人的版面自然不同。个性化三层：被动（行为→画像→编排评分）、主动（拖/留住/半栏）、对话式（「这表换曲线」=块进化）。

## 4. 拆：双向 + 第六去向（本版新增「提醒」）

**A. 答卡拆件**（问出来→拆进版面）：AI 回答=可拆件集合（[整版周报][只要数据][只要曲线]），点一下落折上。

**B. 来件拆路**（送上门→点头路由）：消息/邮件/信号 → 提取 → 预拆解多行，每行带去向标签 →「照此拆解」→ 各件飞进各家+原件消。

**去向六枚举**（标签可点轮换）：

| 去向 | 落点 | 形态 |
|------|------|------|
| 待办 | 计划栏目 | plan 行（source=jev-route） |
| 工作项 | 主线栏目 | 里程碑行；无栏目则立新 |
| 备忘 | 备忘栏目 | 随手记行 |
| 存档 | 只进账 | 不物化，可召回 |
| 丢弃 | 不进账 | 划线排除 |
| **提醒** ⭐新 | 提醒中心 | 定时/条件提示卡 |

**对话即设定**：输入场说「晚上 9 点提醒我看日报」→ 提取时间+事项 → 建提醒——同一台拆解机器，第六去向的默认入口。

**C. 组件进化（拖入对话，一句话调优）** ⭐本版补全（原开放问题 4 的答案）：

- **入口三个**：① 抓组件 kick 行拖到左栏输入框，松手=挂「对象芯片」（跟建议 chip 同族，amber-bg 小带+×可移除，可多挂）② 组件 kick 行的 [留住][×] 旁加 **[调]**——点它=组件推入对话（芯片自动挂上+输入框 focus）③ 自然语言指代（「把刚才那个周报换成曲线」→ AI 猜最近组件，挂芯片确认——先猜后问）
- **万物皆可拖**：不只栏目——待办行、来件卡、轨迹段、报表件、镜里的画像卡，拖进输入框=成为对话对象（「这个待办拆成三步」「这段轨迹为什么算摸鱼」）。屏幕上任何东西+一句话=一次定向指令
- **改参数不改画**：每个组件有结构化定义 `{moduleId, query, params(时间窗/图表型/粒度/标题), version}`——AI 收到指令 → 意图解析 → **参数 diff → 组件就地重渲染**（原位置更新，不新生成）；旧版本自动进账本可召回（消除不丢）；组件角上加小 ◇ 修订标，点开看版本链
- **意图解析接 jev**：调整指令是封闭集合（改图表型/改时间窗/改粒度/改标题/合并/拆分/换数据源/撤销）——choice 小题，先规则关键词后模型；歧义时反问二选一

**单一事实源契约**：手动待办（source=manual）、来件拆解（jev-route）、Oner 同步（oner）、AI 生成（ai）写同一张 plan 表。呈现层（待办栏目/待办树/提示框）只是视图。

## 5. 主动消息系统（本版核心新增）

**消息总线**：care/问卡/提醒/观察卡/例程 → 统一入队（类型+优先级+预算标记）→ 调度器（注意力预算：系统发起扣额度，用户自设免检）→ 双呈现：

- 主窗开着 → **左栏对话流**：AI 主动发起一条（◇ Aura kick，与应答同形）
- 主窗没开 → **桌宠气泡**（优先级队列复用气泡系统 v6）

**三条规则**：
1. **主动消息也是对话**——可直接回（快捷数字/一句话），不是读完即焚的通知。这是优于 OS 通知的根本
2. **未读不丢**——气泡 TTL 过 → 左栏顶部「待处理」行（amber 标记），点开续上
3. **文案统一四段式**：「状态 + 洞察 + 具体提议 + 二选一」。例：*已经 18:40 了。今天剩 2 条待办没动、其中 1 条标了今晚。① 现在生成明日章并挪到明早 ② 保持今晚* ——填不进模板的消息不许发

**提醒中心**（替代 OS 通知，全应用内）：用户定时（「晚上提醒我」）/ 条件定时（「这个修完提醒我」挂观察卡）/ 系统建议（走预算）。弹出形态：主窗=折下 amber 卡置顶；桌面=桌宠走近+气泡；托盘兜底。

## 6. 桌宠状态语言（三级打扰模型）

桌宠=唯一桌面常驻 + 状态提示器。**显示状态与发起打扰是两个通道**：

| 级 | 通道 | 用途 | 打扰成本 |
|----|------|------|---------|
| 姿态 | 站/坐/打盹/视线方向/表情/朝向 | 持续状态：专注=安静工作态、摸鱼=歪头、会议=正坐、空闲=趴眠 | 零（余光可读可忽略） |
| 气泡 | 举手/铃铛+气泡 | 主动消息（问卡/建议/低优先提醒），走预算 | 中 |
| 走近 | 移动到视线焦点+挥手 | 用户自设定时提醒到点、重要确认 | 高（用户自设，不烦） |

15 开关的新语义：`clips`=姿态语言载体、`chatter`=气泡通道、`care`=消息源、`roam`=走近的 locomotion 基础、`intro`=首启仪式感入口。放回顺序按此重排（姿态三件套→走近→氛围件）；`chat`（右键聊天）退役。

## 7. 交互自进化（本版独有，超越竞品的闭环）

**快捷回复协议**：选项带编号①②，回数字即答（气泡上=大按钮，主窗=点或打字）。**元协商**：用户表现出习惯（总回「好」/「y」）→ WorkOn 提一次「以后『是』类就认这个词？」→ 一次确认永久生效，存画像「交互习惯」层。

**应答信号**（每条主动消息自动记录）：立即快捷回（强正）/ 看而未回（中）/ 忽略（负）/ 迟到续上（弱正）/ 主动纠正（负+金标）。附：时延、当时专注态、通道。

**五维进化**：时机（忽略 18:00 提醒×5 天→例程自动漂到 20:00，可解释）/ 频率（同类连忽 3 天→降频或并进日报）/ 形式（不回长消息→收缩为单行）/ 通道（不理气泡→偏主窗）/ 专注阈值（专注中被弹 3 次全忽略→该类获专注静默）。

**护栏三条**：①学到的习惯在镜里一张清单（「它学会的你的习惯」），可改可删 ②降频可自动、升频必须点头 ③每次进化可解释（「为什么 20 点才找我？——你连 5 天 18 点没理我」）。

**jev 新题型**：应答预测 noul（P(用户会回应这条)）→ 调度器决定现在发/攒到断点/降级日报；模糊回复意图 choice（确认/推迟/拒绝/改条件）。先规则后模型，数据攒够进重训。

## 8. 智能三层分工 + jev 概率语言

| 层 | 引擎 | 吃什么 | 吐什么 | 频率 |
|----|------|--------|--------|------|
| 秒级·结构化 | 规则+XGBoost | 9 结构化特征 | work_state | 每 2s tick |
| 秒级·语义 | **jev 0.6B**（已训好） | 窗口标题/OCR/**文件变更摘要**⭐新 | 场景三级/动作/微活动/文件事件分类，校准概率 | 窗口切换/变更窗口异步 |
| 低频·生成 | LLM（云/Ollama） | 脱敏上下文 | 日报/状态卡/对话/拆解文本 | 段级/按需 |

**仲裁规则**：work_state 主判=XGBoost；jev 仅在 XGBoost<0.75 时当第二意见。场景题归 jev 独占。**生成归 LLM，把关归 jev**（LLM 提议的 completed 待办，jev noul P<0.7 降回 deferred）。

### 8.1 文件变动监控 × jev（⭐本版新增）

**管道**：fs.watch 事件流（突发性：npm install 千条）→ **合并器**（每项目 60s 窗口聚合成变更摘要：文件数/扩展名分布/路径样本/git ±行数）→ 渲染 state 文本 → jev 题组 → 路由。

**题组**（questions.json 扩展）：
- `file_class`（choice 9）：source_edit / build_artifact / dependency / generated / config / docs / test / assets / temp
- `work_activity`（choice 6）：feature / bugfix / refactor / docs / experiment / chore
- `is_deliverable`（noul）：该窗口是否构成值得记账的产出（喂 chain/ 产出闭环）
- `project_match`（choice）：归属哪个绑定主线（>26 先规则粗筛）

**为什么是 jev 不是 LLM**：封闭集合+要概率+高频+本地——四个条件全中；**零 token**（本地 196ms）；**隐私**（只看路径/扩展名/变更量，永不读内容）；LLM 只在歧义窗口被可选升级，或用 jev 的分类聚合写日报句子。

**训练数据免费来源**：git 历史 = 金标生成器——commit diff → 变更摘要文本，commit message/类型 → 标签，用户自己仓库+开源仓库可生成数千条真实样本，零人工标注；devSession 结算记录补充。

**落地顺序**：dirWatcher 现有四信号规则保留 → 攒窗口摘要+git 对照 → 训 file_class/work_activity → shadow → 接管分类；is_deliverable 先走现有产出闭环模板。注意：忽略规则沿用 .gitignore 语义；窗口自适应（空闲长窗口/活跃短窗口）；可选 git status --porcelain 定时快照替代 fs.watch 聚合做校准。

### 8.2 概率 → UI 语言

jev 校准概率是所有置信度显示的唯一来源（显示诚实度）：来件拆路去向标签默认选最高分、分差小 amber 标出；对话可说「85% 确定在改主线的 bug，但项目归属只有 62%——A 还是 B？」；未校准不显示数字。

## 9. 记忆与镜

**镜 = 一切后台**，五个分区：设置 / **记忆 moodboard**（人卡片·情绪板·目标卡·宠物照护式生活块，不是表格）/ 隐私（分层 L0-L4+访问日志）/ **习惯清单**（「它学会的你的习惯」，可改可删）/ **例程清单**（人话列表：「邮件每 2h 整理 · 西语周二四 20:30 · 晚间章每天 21:00」，点开可改——automation 从 AutomationLab 深处搬到明面）。

## 12. 架构落地（数据契约）

1. **单一事实源**：plan/todo/提醒 同表多 source（manual/jev-route/oner/ai/system）
2. **栏目流协议**：后端不再发「视图」，发结构化栏目事件（落/消/留住/改路由），前端活页只消费事件——L5 从 16 视图重写为栏目数据契约
3. **消息总线 API**：`bus.publish({source, type, priority, budgetTag, payload})` → 调度器 → 左栏/桌宠双通道；应答回流 `bus.respond(msgId, answer)` → 账本
4. **应答账本**：recognition_log 旁新增 interaction_log（消息 id/信号类型/时延/专注态/通道/答案）
5. **模块退役/保留**：L1-L3 引擎全保留（壁垒）；SuggestionWidget/右键 chat/perspective 路由退役；todoWidget 待新前端跑稳后再拍板
6. **本地 LLM 插槽**：能力插槽补 Ollama/LM Studio 适配器（AI 能力开箱即用，不配 key 不全盲）
