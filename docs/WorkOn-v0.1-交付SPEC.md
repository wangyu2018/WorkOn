# WorkOn v0.1 — 产品交付 SPEC

> 版本：v0.1 ｜ 日期：2026-07-25 ｜ 状态：交付基线
> 一句话：本地优先的桌面工作记录系统 + VRM 3D 桌搭（姵儿），免安装绿色交付。

---

## 1. 产品定位

- **本地优先**：全部数据（活动轨迹/计划/问答/设置）仅存本机 `userData`，不上传任何服务器
- **效率 + 桌搭集合体**：每秒自动记录工作状态（13 种），AI 画像复盘；3D 桌搭姵儿伴随工作状态实时联动
- **离线可用**：核心功能 0 网络依赖；AI 分析为可选增强（OpenAI 兼容接口，Key 仅存本机）

## 2. 核心功能

| 模块 | 能力 |
|------|------|
| 监控 | 前台窗口每秒采样、13 种工作状态自动识别、双屏并行追踪、MiniTrailBar 当日概览、应用分类纠偏规则 |
| 日历 | 24h 时间轴（22–88px/h 竖向缩放）、监控轨迹 + 手动补录 + 计划虚线叠加层、今日统计摘要、周视图、7 天热力图 |
| 计划 | 计划 CRUD、完成比例滑杆、延期、vs 实际达成率、规则引擎延期预测、自定义分类 |
| 报表 | 日报/周报、AI 洞察（可关闭）、状态分布可展开到应用明细 |
| 问答 | 工作数据上下文问答（AI 未配置时本地规则回退）、姵儿头像气泡 |
| 桌搭 | VRM 3D 姵儿、16 状态空间行为、90+ 句场景化主动搭话、点击/拖拽/右键聊天、PAD 情感同步、亲密度养成 |
| 深度模式 | 定时截图 + 本地 Tesseract OCR（chi_sim+eng，语言包随包离线分发）、25 类内容关键词增强识别 |
| 隐私 | 应用级不采集标记（不截屏/不 OCR/不记标题，仅记活跃时长）、OCR 缓存周期清理 + 一键清理 |
| 集成 | WebSocket 广播、state.json 快照、Oner 待办同步（能力开关 + 折叠详情） |
| 会议 | 会议软件检测：每次询问 / 一键隐身 / 免打扰 / 会议辅助（自动补录会议条目） |

## 3. 桌搭交互与气泡

- **单气泡实例**：任何时刻最多一个气泡；`show()` 直接替换内容（用户气泡侧下 / 角色气泡头顶，变体切换），思考 → 回答无缝覆盖同一气泡，物理上不可能重叠
- 气泡 v4：≤15 字单行紧凑；长文本最多 280px × 8 行正方形；3x 超采样 + mipmap；悬停暂停消失 + 放大 1.08
- 互动开关（桌搭页可配）：点击 / 拖拽 / 游荡 / 页面跟随 / 表情反馈 / 右键聊天，关闭即注销对应行为降低开销

## 4. 性能优化与实测数据

### 4.1 优化项

- dt 上限按档位弹性（eco 0.12s / standard 0.06s / 其他 0.05s），eco 档动画不再跑半速
- 自动降级/恢复：阈值跟随档位上限（判定线 = 档位上限 × 0.66，恢复线 = 上限 × 0.92，ultra 档 45/50），修复限帧档被误判降级
- 动态帧率：拖拽/状态过渡临时升帧（来源计数），结束回落
- 闲置降耗：30s 无活动自动切 eco，有活动恢复原档位（显式保存/恢复）
- 懒加载三阶段：场景光照先行 + 加载占位，VRM 贴图各向异性延迟到首帧后
- Animator 收敛快路径（骨骼混合收敛后跳过 lerp）、粒子按密度概率跳帧
- 亮度：ACES 色调映射（曝光 1.15）+ Fill 0.65 / Hemisphere 0.55
- 头发物理：scale 突变 >3% 时额外 3 帧收敛，消除慢落

### 4.2 实测（本机：16 逻辑核，200% DPI，含主窗口/悬浮窗/桌宠/GPU 全部进程）

| 帧率档位 | 实测 FPS | CPU 占用 | 总内存 | drawCalls | 三角形 | 降级 |
|---------|---------|---------|-------|-----------|--------|------|
| eco 省电 | 10 | **2.6%** | 1720 MB | 31 | 90,921 | 否 |
| standard 标准 | 20 | 3.4% | 1950 MB | 27 | 84,823 | 否 |
| smooth 流畅（默认） | 30 | 3.4% | 2288 MB | 27 | 84,823 | 否 |
| ultra 极致 | 111 | 6.2% | 2321 MB | 31 | 90,921 | 否 |

- 闲置 30s 自动降 eco（≈2.6% CPU），交互即刻恢复原档位
- 启动：场景光照即时可见，VRM 加载期有「姵儿正在赶来…」占位提示

## 5. 离线部署（免安装）

### 交付物

```
dist/WorkOn-win32-x64/          绿色版目录（解压即用，无需安装/管理员权限）
└─ WorkOn.exe                   入口（已内嵌 WorkOn 图标）
dist/WorkOn-win32-x64.zip       同内容压缩包（交付/分发用）
```

- 运行时依赖已随包：Electron 运行时 + `ws` + `sharp`（含 win32-x64 原生二进制）+ OCR 语言包（`resources/app/assets/*.traineddata`）
- **0 网络依赖可用**：监控/日历/计划/报表/桌搭/OCR 全离线；仅 AI 分析和 Oner 同步需要网络
- 数据位置：`%APPDATA%/workon/`（settings.json、db.json、activities.jsonl、screenshots/），删除目录即完全卸载
- 单实例锁：重复启动只会唤出已有主窗口

## 6. 技术架构

- Electron 33 + electron-vite + React 18 + TypeScript（双端 tsc 严格类型检查）
- 三窗口：主窗口（React SPA）/ 悬浮窗（玻璃问答卡）/ 桌宠窗（全屏透明 overlay，区域点击穿透）
- 3D：three.js + @pixiv/three-vrm（VRM 姵儿，97 骨骼归一化映射，髋高 130px 基准）
- 存储：JSONL 活动流 + db.json 集合（防抖落盘，14 天保留期）
- OCR：tesseract.js v5（主进程 worker，30s/次）+ sharp 预处理

## 7. 已知限制

- 打包版暂未做代码签名，Windows SmartScreen 首次运行可能提示「未知发布者」
- AI 功能需自备 OpenAI 兼容 API Key；未配置时相关入口自动隐藏，本地规则回退
- OCR 深度模式默认关闭（隐私考虑），开启后截图存本机 screenshots/ 并可一键清理
- 多显示器下桌宠仅跟随主显示器
